## English

### Overview

This repository provides clean, standalone Russian localization files for **SmartMobs v1.4.1**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `config.yml`: Complete Russian configuration file (all 318 keys and comments) replacing English defaults.

### Installation

1. Copy `config.yml` into `plugins/SmartMobs/config.yml`.
2. Run `/smartmobs reload` or restart your server.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **SmartMobs v1.4.1**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `config.yml`: Полный файл конфигурации на русском языке (все 318 ключей и комментарии), заменяющий английский оригинал.

### Установка

1. Скопируйте файл `config.yml` в папку `plugins/SmartMobs/config.yml`.
2. Выполните команду `/smartmobs reload` или перезапустите сервер.
